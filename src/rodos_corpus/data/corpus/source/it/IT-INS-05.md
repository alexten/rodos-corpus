## 1. Назначение и область применения

1.1. Настоящая инструкция описывает порядок приёма входящих документов (УПД, счетов-фактур, актов) от поставщиков через систему электронного документооборота «Диадок» (далее — ЭДО).

1.2. Инструкция предназначена для бухгалтера по расчётам с контрагентами. Порядок отправки исходящих документов описан отдельно в ИТ-ИНС-04 — настоящая инструкция его не дублирует.

1.3. С 1 апреля 2026 года входящие документы принимаются в новой версии формата УПД — см. ИТ-РЕЛ-ЭДО-2026-03.

## 2. Проверка входящих документов

2.1. В обработке «Диадок: входящие документы» новые документы отображаются со статусом «Получен, требует рассмотрения». Обработка открывается автоматически при входе в 1С:Бухгалтерия, если есть непросмотренные документы.

2.2. Бухгалтер сверяет данные документа (номенклатура, количество, сумма) с документом-основанием — договором и, если есть, заявкой на закупку. Расхождения фиксируются без принятия документа.

2.3. Срок приёмки входящего УПД от поставщика — один рабочий день с даты получения, как установлено ГРАФИК-ДО-2026.

## 3. Приёмка документа

3.1. При отсутствии расхождений бухгалтер нажимает кнопку «Подписать» — документ подписывается электронной подписью бухгалтера и одновременно создаёт документ поступления в 1С:Бухгалтерия либо связывается с уже созданным документом поступления.

3.2. Для поступлений материалов документ поступления в ЭДО дополнительно должен быть сопоставлен с документом поступления в 1С:ERP (см. ИТ-ИНС-02, раздел 2) — система не связывает их автоматически между двумя контурами.

## 4. Отказ от приёмки

4.1. При обнаружении расхождения (количество, цена, номенклатура) бухгалтер нажимает «Отклонить» и указывает причину текстом — без указания причины отклонение недоступно.

4.2. Отклонённый документ уведомляет отправителя автоматически; повторно связываться с поставщиком по электронной почте не требуется, если причина отклонения полностью описана в поле причины.

4.3. Об отклонении документа от постоянного поставщика (например, ООО «Прикамье-Прокат», АО «Уралметснаб») бухгалтер дополнительно сообщает начальнику отдела снабжения — расхождение может быть связано с отгрузкой, а не с оформлением документа.

## 5. Частые ошибки и что делать

5.1. Ошибка: документ подписан без сверки с договором — расхождение обнаруживается позже, при оплате. Решение: перед подписанием обязательно открывать документ-основание; отменить подписанный и отправленный документ поставщику нельзя, оформляется корректировочный документ.

5.2. Ошибка: один и тот же входящий документ обработан дважды разными сотрудниками — в системе образуется два документа поступления. Решение: не удалять документы самостоятельно; сообщить главному бухгалтеру для аннулирования дубликата.

5.3. Ошибка: документ поступления в ЭДО не сопоставлен с поступлением в 1С:ERP — расхождение между бухгалтерским и складским учётом. Решение: выполнить сопоставление вручную через кнопку «Связать с документом 1С:ERP» в карточке документа ЭДО.

5.4. Ошибка: отклонение отправлено без указания причины по невнимательности (текст скопирован не полностью). Решение: связаться с поставщиком напрямую и продублировать причину письмом, поскольку повторно отредактировать отправленный отказ нельзя.

5.5. Если документ не удаётся ни подписать, ни отклонить из-за технической ошибки, оформляется заявка в службу поддержки с указанием номера документа и наименования контрагента.
