## 1. Что изменилось

1.1. При проведении документа «Требование-накладная» система теперь автоматически сверяет списываемое количество материала с остатком лимита по действующей лимитно-заборной карте цеха на текущий месяц (например, ЛЗК-2026-09).

1.2. При превышении остатка лимита документ не проводится, система выводит сообщение «Превышен лимит по ЛЗК» с указанием доступного остатка.

1.3. Ранее превышение лимита фиксировалось только при последующей сверке бухгалтерией по итогам месяца и не блокировало списание в момент проведения документа.

1.4. Остаток лимита по каждой позиции лимитно-заборной карты обновляется в 1С:ERP сразу после проведения каждого документа списания — отдельного пересчёта или ожидания ночной регламентной обработки не требуется.

## 2. Для кого

2.1. Изменение затрагивает кладовщиков складов материалов всех трёх площадок, оформляющих списание материалов в 1С:ERP (см. ИТ-ИНС-02).

2.2. Начальники цехов дополнительно получают возможность утверждать увеличение лимита цеха при обоснованной потребности — соответствующий пункт добавлен в раздел «Склад» → «Лимитно-заборные карты» → «Утвердить увеличение лимита».

## 3. Что нужно сделать пользователю

3.1. Кладовщикам необходимо заранее проверять остаток лимита цеха перед крупным списанием — остаток отображается в карточке лимитно-заборной карты цеха.

3.2. При отказе в проведении документа по причине превышения лимита кладовщик обращается к начальнику цеха для утверждения увеличения лимита — порядок описан в ИТ-ИНС-02, раздел 3.

## 4. Известные ограничения

4.1. Контроль лимита применяется только к материалам, включённым в лимитно-заборную карту цеха; списание прочих материалов, не включённых в карту, контролю по лимиту не подлежит.

4.2. Утверждение увеличения лимита доступно только начальнику цеха и не может быть делегировано мастеру участка.

4.3. Контроль применяется к спискаемому количеству по документу целиком: частично провести требование-накладную в пределах остатка лимита, а оставшуюся часть — сверх лимита, нельзя, документ либо проводится полностью, либо не проводится вовсе.

## 5. Сроки

5.1. Функция контроля лимитов включена на всех трёх площадках 24.08.2026 и применяется начиная с лимитно-заборных карт на сентябрь 2026 года.
