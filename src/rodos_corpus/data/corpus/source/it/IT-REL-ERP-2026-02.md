## 1. Что изменилось

1.1. В системе «1С:ERP Управление предприятием» добавлен новый отчёт «Загрузка цехов»: раздел «Производство» → «Отчёты» → «Загрузка цехов».

1.2. Отчёт показывает по каждому цеху и участку плановую и фактическую загрузку оборудования за выбранный период на основании открытых производственных заказов и данных о выработке.

1.3. Отчёт строится с детализацией до участка (например, участок ЧПУ цеха №1) и позволяет сравнивать плановую загрузку с фактической за смену, сутки или произвольный период.

1.4. В отчёте предусмотрено два режима вывода: табличный (проценты загрузки по строкам «Цех» и «Участок») и графический (столбчатая диаграмма загрузки за выбранный период) — переключение режима выполняется кнопкой «Вид» в правом верхнем углу отчёта.

## 2. Для кого

2.1. Отчёт доступен главному технологу, инженерам-технологам и начальникам цехов.

2.2. Менеджерам по продажам и бухгалтерии отчёт недоступен — состав прав доступа не менялся, изменение затрагивает только раздел «Производство».

## 3. Что нужно сделать пользователю

3.1. Отдельная настройка не требуется — отчёт появляется в списке отчётов автоматически после установки обновления.

3.2. При первом открытии отчёта рекомендуется задать период по умолчанию через кнопку «Настройка отчёта» — без настройки отчёт по умолчанию показывает данные за текущую смену.

3.3. Порядок работы с производственными заказами не меняется — см. ИТ-ИНС-01. Настоящий релиз добавляет только новый отчёт для анализа загрузки, не затрагивая создание и ведение заказов.

## 4. Известные ограничения

4.1. Отчёт не учитывает время внепланового простоя оборудования, зафиксированное отдельными документами простоя, — плановая загрузка рассчитывается только от производственных заказов.

4.2. При открытии отчёта за период дольше трёх месяцев формирование может занимать до одной минуты — это ожидаемое поведение, не является сбоем.

4.3. Отчёт не разделяет площадки автоматически при открытии — при работе с несколькими площадками пользователь выбирает нужную площадку в отборе отчёта; без выбора отчёт показывает данные по всем трём площадкам одновременно, что затрудняет чтение при большом числе цехов.

## 5. Сроки

5.1. Обновление установлено на всех трёх площадках в ночь на 02.03.2026, отчёт доступен с начала рабочего дня 02.03.2026.
