## 1. Назначение

1.1. Настоящий реестр содержит перечень учётных записей сотрудников в информационных системах предприятия. Реестр не содержит паролей и персональных данных сверх фамилии, имени, отчества и должности.

1.2. Логин учётной записи соответствует адресу корпоративной почты сотрудника без домена (например, `i.ushakova` для адреса `i.ushakova@rodos-detal.example.com`) и является единым для всех систем, к которым у сотрудника есть доступ.

1.3. Реестр пересматривается не реже одного раза в квартал. По итогам инцидента ИТ-ИНЦ-2026-08 09.09.2026 проведён внеплановый сплошной пересмотр всех учётных записей реестра; данные актуальны по состоянию на эту дату, если в столбце «Дата последнего пересмотра» не указано иное.

1.4. Гриф «Для служебного пользования» установлен в связи с тем, что реестр в сводном виде раскрывает состав системного доступа сотрудников.

## 3. Пояснения

3.1. Доступ к почте, файловому серверу (в пределах папок своего подразделения) и службе поддержки предоставляется каждому сотруднику при оформлении в отделе кадров и не требует отдельной заявки — см. ПАМЯТКА-001, п. 3.2.

3.2. Доступ ко всем прочим системам, перечисленным в столбце «Системы», предоставляется по заявке непосредственного руководителя через службу поддержки в соответствии с ролью сотрудника.

3.3. Учётная запись `a.vereschagin` оставлена в реестре в статусе «уволен, учётная запись заблокирована» для истории; данные о привилегированных (административных) учётных записях, которыми пользовался этот сотрудник, отражены отдельно в ИТ-РЕЕСТР-УЗ-ПРИВИЛЕГ.
