## 1. Что изменилось

1.1. В печатную и экранную форму сменного задания добавлен столбец «Отклонение» — разница между плановым и сданным количеством по операции, рассчитывается автоматически.

1.2. Положительное отклонение (перевыполнение) отображается обычным шрифтом, отрицательное (невыполнение плана) — выделяется цветом на экране цехового терминала и в печатной форме.

1.3. Значение столбца рассчитывается по формуле «Сдано минус План» и обновляется в реальном времени по мере отметок о выработке на цеховом терминале — вручную вводить или пересчитывать отклонение не требуется.

1.4. Изменение затрагивает только форму отображения сменного задания. Порядок формирования сменного задания из производственных заказов не менялся.

## 2. Для кого

2.1. Изменение затрагивает мастеров участков, начальников цехов и операторов оборудования, работающих со сменным заданием на цеховом терминале (см. ИТ-ИНС-09) и с бумажной печатной формой.

2.2. Инженерам-технологам и главному технологу столбец полезен при анализе причин отклонений по операциям при разборе несоответствий — отдельного отчёта по отклонениям релиз не добавляет, данные доступны только в самом сменном задании.

## 3. Что нужно сделать пользователю

3.1. Отдельных действий пользователя не требуется — столбец «Отклонение» появляется автоматически при первом открытии сменного задания после обновления.

3.2. Начальникам цехов рекомендуется довести до операторов, что отрицательное отклонение — это плановый рабочий показатель для анализа выполнения задания, а не автоматическая фиксация нарушения.

## 4. Известные ограничения

4.1. Столбец «Отклонение» не пересчитывается автоматически на уже распечатанных бумажных бланках сменного задания за прошлые смены — для них отклонение считается вручную, как и раньше.

4.2. На цеховых терминалах прежней версии (до обновления, см. ИТ-РЕЛ-ТЕРМИНАЛ-2026-09) столбец отображается без цветового выделения — только числовое значение.

4.3. Отклонение по операции, ещё не закрытой оператором (см. ИТ-ИНС-09, п. 4.4), считается предварительным и может измениться до момента завершения операции — окончательным считается значение после нажатия кнопки «Завершить операцию».

## 5. Сроки

5.1. Обновление формы установлено на всех трёх площадках 20.05.2026 и применяется ко всем сменным заданиям, сформированным начиная с этой даты; ранее сформированные и уже распечатанные сменные задания повторно не перепечатываются.
