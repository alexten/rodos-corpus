## 1. Назначение и область применения

1.1. Настоящий порядок устанавливает правила антивирусной защиты рабочих станций, серверов и цеховых терминалов ГК «Родос-Деталь», а также правила использования съёмных носителей информации.

1.2. Порядок обязателен для всех сотрудников, использующих технику предприятия, и для системного администратора.

## 2. Термины и сокращения

- Съёмный носитель — USB-накопитель, внешний жёсткий диск, карта памяти и иное устройство хранения данных, подключаемое к рабочей станции.
- Сигнатурная база — набор данных антивирусного программного обеспечения для распознавания известного вредоносного кода.

## 3. Установка и обновление антивирусного программного обеспечения

3.1. Антивирусное программное обеспечение устанавливается системным администратором на все рабочие станции, серверы и цеховые терминалы предприятия без исключения.

3.2. Обновление сигнатурных баз производится автоматически не реже одного раза в сутки при наличии сетевого подключения; при работе вне сети предприятия обновление производится при первом подключении к сети или через удалённый доступ.

3.3. Отключение или приостановка работы антивирусного программного обеспечения сотрудником самостоятельно запрещается; временное отключение для технических работ производится только системным администратором с последующим включением по завершении работ в тот же рабочий день.

3.4. Новая техника, поступившая по регламенту закупки компьютерной техники и лицензий (ИТ-РЕГЛ-ЗАКУПКА-ТЕХ), подключается к сети предприятия только после установки антивирусного программного обеспечения и обновления сигнатурной базы.

## 4. Проверка рабочих станций

4.1. Полная проверка рабочей станции на наличие вредоносного кода производится автоматически не реже одного раза в неделю в фоновом режиме.

4.2. Проверка в режиме реального времени (контроль запускаемых файлов и открываемых документов) включена постоянно и не может быть отключена сотрудником.

4.3. Для цеховых терминалов, эксплуатируемых в условиях повышенной запылённости и вибрации (цеха №1 и №2), полная проверка по пункту 4.1 назначается на время, не совпадающее с рабочей сменой участка, чтобы не снижать быстродействие терминала во время работы оператора.

4.4. Системный администратор ведёт учёт результатов еженедельных проверок и хранит их не менее 12 месяцев для целей расследования инцидентов информационной безопасности.

## 5. Действия при обнаружении вредоносного кода

5.1. При обнаружении вредоносного кода антивирусное программное обеспечение изолирует заражённый файл автоматически и уведомляет системного администратора.

5.2. Системный администратор обязан приступить к анализу инцидента не позднее 1 часа с момента получения уведомления об обнаружении вредоносного кода, классифицируемого как шифровальщик, и не позднее 4 часов — для иных видов вредоносного кода.

5.3. При признаках заражения программой-шифровальщиком рабочая станция немедленно отключается от сети предприятия системным администратором, а дальнейшие действия выполняются в порядке, установленном планом восстановления работоспособности информационных систем (ИТ-ПЛАН-DRP).

## 6. Контроль съёмных носителей

6.1. Подключение съёмных носителей к рабочим станциям и цеховым терминалам предприятия разрешается только сотрудникам, которым такое право предоставлено по согласованию с руководителем ИТ.

6.1.1. Перечень сотрудников, которым предоставлено право подключения съёмных носителей, ведёт системный администратор и пересматривает не реже одного раза в год.

6.2. Любой съёмный носитель при подключении к рабочей станции предприятия автоматически проверяется антивирусным программным обеспечением перед предоставлением доступа к его содержимому.

6.3. Подключение личных съёмных носителей к цеховым терминалам запрещается в соответствии с регламентом эксплуатации цеховых терминалов (ИТ-РЕГЛ-ТЕРМИНАЛ, п. 5.1).

6.4. Использование съёмных носителей для переноса документов, содержащих сведения, составляющие коммерческую тайну, допускается только с письменного разрешения, предусмотренного положением о коммерческой тайне (ПОЛ-КТ-001, п. 3.3.1).

## 7. Ответственность

7.1. Ответственность за работоспособность антивирусного программного обеспечения на всех рабочих местах несёт системный администратор.

7.2. Ответственность за использование несогласованных съёмных носителей несёт сотрудник, у которого они обнаружены.

7.3. Ответственность за организацию антивирусной защиты предприятия в целом несёт руководитель ИТ.
