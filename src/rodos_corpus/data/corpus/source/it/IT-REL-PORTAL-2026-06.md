## 1. Что изменилось

1.1. Запущен внутренний портал документов — веб-страница для просмотра регламентов, инструкций и шаблонов из общих папок файлового сервера `\\rodos-fs\Обмен` без необходимости подключения сетевого диска.

1.2. Портал не является новой системой хранения документов: он показывает те же документы и с теми же правами доступа по подразделениям, что и общие папки файлового сервера — портал добавляет только удобный веб-интерфейс для чтения.

1.3. Портал доступен по внутренней ссылке с любого рабочего компьютера предприятия без установки дополнительного программного обеспечения — достаточно браузера.

## 2. Для кого

2.1. Портал доступен всем сотрудникам, у которых есть права на соответствующие общие папки файлового сервера — состав прав не меняется, портал использует те же группы доступа.

2.2. Портал особенно полезен сотрудникам, редко работающим за компьютером и не имеющим привычки подключаться к сетевым папкам вручную (например, мастерам участков).

## 3. Что нужно сделать пользователю

3.1. Отдельная регистрация на портале не требуется — вход выполняется автоматически под корпоративной учётной записью, под которой сотрудник уже вошёл на компьютер.

3.2. Сохранение новых документов по-прежнему выполняется через общие папки файлового сервера, как описано в ИТ-ИНС-08, — портал предназначен только для просмотра и не заменяет порядок сохранения документов, включая подпапку «ВходДляАссистента».

## 4. Известные ограничения

4.1. Портал доступен только из сети предприятия и через VPN (см. ИТ-ИНС-06); из внешней сети без VPN портал недоступен.

4.2. Портал позволяет только просматривать и скачивать документы; редактирование документов на портале не предусмотрено — для изменения документа он по-прежнему открывается и сохраняется через общую папку файлового сервера.

4.3. Поиск на портале ищет только по названию файла и названию подпапки, полнотекстовый поиск по содержимому документов в первой версии портала не реализован — это учтено при планировании следующих релизов.

## 5. Сроки

5.1. Портал доступен на всех трёх площадках с 22.06.2026.
