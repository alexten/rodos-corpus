## 1. Оборудование

1.1. Круглошлифовальный станок 3М151, инвентарный номер ОС-1066, цех №2, шлифовально-доводочный, Ковровская площадка.

## 2. Описание неисправности

2.1. Периодическим контролем 10.08.2026 зафиксирован рост биения шпинделя до 0,025 мм при допуске по станку 0,03 мм — тенденция приближается к предельному значению, критичному для допуска по биению деталей.

## 3. Влияние на производство

3.1. Риск выхода за допуск по биению 0,03 мм у деталей 45.67.89, 45.67.90 и штоков 73.22.30, 73.22.31, обрабатываемых на этом станке. До замены — усиленный контроль ОТК каждой третьей детали.

## 4. Требуемые работы и запасные части

4.1. Замена подшипников шпиндельного узла, регулировка, проверка биения по контрольному образцу после ремонта.

4.2. Требуются прецизионные подшипники шпинделя по спецификации станка, заказ через отдел снабжения.

## 5. Предлагаемое окно остановки

5.1. 24.08.2026–26.08.2026, три рабочих дня, в соответствии с графиком ППР PPR-2026.
