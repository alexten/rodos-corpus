## 2. Маршрут обработки

### 015 Токарная

Оборудование: Sinumerik 828D / СТЦ-1730, инв. № ОС-1250.
Инструмент: Резец проходной с пластиной CNMG 120408.
Режимы: скорость 180…220 м/мин, подача 0,25 мм/об, глубина 1,5…2,5 мм.
Охлаждение: СОЖ ЭТ-2, 5…7 %.

### 045 Сверлильная

Оборудование: Sinumerik 828D / СТЦ-1730, инв. № ОС-1250.
Инструмент: Сверло ø12 Р6М5.
Режимы: скорость 25…30 м/мин, подача 0,12 мм/об, глубина —.
Охлаждение: СОЖ ЭТ-2, 5 %.

### 070 Контроль ОТК

Оборудование: по указанию мастера участка.
Инструмент: Штангенциркуль, микрометр, индикаторная головка.

## 3. Контролируемые параметры

| Параметр | Норма |
| --- | --- |
| поле допуска отверстия | ø110 H7 |
| шероховатость Ra, мкм, не более | 1.6 |

3.1. Контроль выполняется на операции 070 контролёром ОТК по методике ОТК-МИ-001.
3.2. При отклонении параметра деталь не передаётся на следующую операцию; оформляется извещение о несоответствии по регламенту ОТК-РЕГЛ-003.

## 4. Требования охраны труда

4.1. К работе допускаются лица, прошедшие инструктаж по инструкции ИОТ-005 «Общие требования охраны труда для работников механических цехов».
4.2. Применение средств индивидуальной защиты обязательно на всех операциях механической обработки.
