## Приказ № 131 от 10.08.2026

Во исполнение пункта 3 приказа № 112 от 13.07.2026 «О мерах по итогам аварии на линии цинкования» и в связи с переработкой инструкции по охране труда для работников гальванического участка по итогам разбора инцидента ИНЦ-2026-05 ПРИКАЗЫВАЮ:

1. Утвердить и ввести в действие с 01.09.2026 инструкцию по охране труда для работников гальванического участка, редакция 2 (ИОТ-021-r2).

2. Считать утратившей силу с 01.09.2026 инструкцию по охране труда для работников гальванического участка, редакция 1 (ИОТ-021-r1).

3. Начальнику цеха №4 организовать внеочередной инструктаж всех работников гальванического участка по ИОТ-021, ред. 2, с отметкой в журнале инструктажа, в срок до 01.09.2026.

4. Инженеру по охране труда обеспечить размещение экземпляров ИОТ-021, ред. 2, на информационных стендах цеха №4 и изъятие экземпляров ред. 1, до 01.09.2026.

5. Отделу снабжения обеспечить наличие на гальваническом участке средств индивидуальной защиты, предусмотренных ИОТ-021, ред. 2, до начала её действия.

6. Начальнику цеха №4 обеспечить наличие бумажного экземпляра ИОТ-021, ред. 2, непосредственно на рабочих местах гальванического участка для оперативного использования персоналом при выполнении работ.

7. Контроль за исполнением настоящего приказа возложить на инженера по охране труда.
