## 1. Назначение каталога

1.1. Настоящий каталог содержит номенклатуру валов и осей, изготавливаемых ГК «Родос-Деталь» на Ковровской площадке.

1.2. Каталог применяется менеджерами по продажам при подготовке коммерческих предложений и заказчиками при уточнении характеристик продукции.

1.3. Основные заказчики валов и осей — АО «Редмаш», ООО «Привод-НН», ООО «Конвейер-Системс», ООО «Ремсервис-Урал» и дилер ООО «Агротех-Деталь» (категория B).

## 3. Материалы и термообработка

3.1. Большинство валов группы изготавливается из стали 40Х ГОСТ 4543-2016.

3.2. Валы быстроходный и тихоходный редуктора Р-200 (45.67.91, 45.67.92) изготавливаются из стали 38ХС ГОСТ 4543-2016 повышенной прочности.

3.3. Вал натяжной станции (45.67.94) изготавливается из стали 45 ГОСТ 1050-2013 без термообработки.

3.4. Валы с требованием по твёрдости проходят закалку ТВЧ на Ковровской площадке.

## 4. Контроль

4.1. Радиальное биение и геометрия валов контролируются по методике ОТК-МИ-002.

4.2. Твёрдость после термообработки контролируется по методике ОТК-МИ-003.

4.3. Линейные размеры и поля допусков контролируются по методике ОТК-МИ-001.

4.4. Токарная обработка валов выполняется на токарном обрабатывающем центре DMG MORI CTX 310 ecoline (инв. № ОС-1198); круглое шлифование — на станке 3М151 (инв. № ОС-1066), критичном для соблюдения допуска по биению 0,03 мм.

## 5. Технические условия

5.1. Технические условия на вал выходной редуктора Р-160 (45.67.89) — TU-45-67-89, в том числе на английском языке для экспортных поставок — TU-45-67-89-EN.

5.2. Технические условия на остальные валы группы оформляются по запросу заказчика в порядке, установленном регламентом SALES-REGL-KP.

## 6. Порядок заказа

6.1. Коммерческое предложение по номенклатуре настоящего каталога готовится менеджером по продажам по форме SALES-SHABLON-KP либо, при ускоренном сроке изготовления, по форме SALES-SHABLON-KP-SROCH.

6.2. Заказ оформляется в производство после подписания спецификации к договору поставки в порядке, установленном регламентом SALES-REGL-ZAKAZ.
