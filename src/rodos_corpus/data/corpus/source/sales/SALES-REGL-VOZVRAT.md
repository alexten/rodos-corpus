## 1. Назначение и область применения

1.1. Настоящий регламент устанавливает порядок возврата клиентом продукции ГК «Родос-Деталь» и
документального оформления такого возврата.

1.2. Регламент применяется при возврате продукции по подтверждённой рекламации (раздел 3) и при
возврате по соглашению сторон без рекламации (раздел 4).

1.3. Регламент не заменяет SALES-REGL-REKLAM в части приёма и разбора рекламации — возврат оформляется
после того, как рекламация рассмотрена и по ней принято решение о возврате как о способе урегулирования.

## 2. Термины

- Корректировочный УПД — универсальный передаточный документ, которым оформляется уменьшение
  количества или стоимости ранее переданной продукции.
- Основание возврата — документ, подтверждающий причину возврата: акт о браке ОТК, заключение о
  гарантийном случае, письменное соглашение сторон.

## 3. Возврат по рекламации

3.1. Возврат по подтверждённой рекламации оформляется после того, как ОТК подтвердил несоответствие
актом о браке в порядке ОТК-РЕГЛ-004, а менеджер по продажам согласовал с клиентом возврат как способ
урегулирования по SALES-REGL-REKLAM.

3.2. Основанием для оформления корректировочного УПД служит акт о браке; при наличии отчёта 8D в
корректировочном УПД указывается его номер в поле примечания.

3.3. Возвращаемая продукция направляется клиентом на склад готовой продукции в Тольятти либо
утилизируется на месте по отдельному письменному согласованию — способ определяется менеджером по
продажам совместно с начальником склада готовой продукции.

## 4. Возврат по соглашению сторон

4.1. Возврат без подтверждённого несоответствия (например, ошибочный заказ, избыточное количество)
допускается только по индивидуальному письменному согласованию с коммерческим директором.

4.2. Возврат по соглашению сторон возможен только для продукции, не бывшей в эксплуатации и
сохранившей товарный вид и упаковку; решение о возможности такого возврата принимает коммерческий
директор с учётом номенклатуры и давности поставки.

4.3. При возврате по соглашению сторон стоимость логистики несёт клиент, если иное не согласовано
отдельно.

## 5. Оформление корректировочного УПД

5.1. Основание для возврата (акт о браке, заключение о гарантийном случае или письменное соглашение)
менеджер по продажам передаёт в бухгалтерию не позднее одного рабочего дня после согласования возврата
с клиентом.

5.2. Бухгалтерия по расчётам с контрагентами оформляет корректировочный УПД не позднее трёх рабочих
дней с даты получения основания для возврата.

5.3. Корректировочный УПД направляется клиенту через оператора ЭДО и подписывается обеими сторонами;
до подписания клиентом возврат не считается завершённым в учёте.

5.4. Если возврат связан с оплаченной партией, бухгалтерия по расчётам с контрагентами возвращает
денежные средства клиенту или засчитывает их в счёт следующей поставки — способ определяется по
согласованию с клиентом и фиксируется в переписке.

## 6. Особенности для дилеров

6.1. Возврат продукции дилером по дилерскому договору оформляется в общем порядке настоящего
регламента, с учётом того, что скидка, применённая при первичной поставке, учитывается и при
корректировке стоимости в корректировочном УПД.

6.2. Если возврат связан со спором по применённой скидке, а не с качеством продукции, регламент не
применяется — такой спор рассматривается в рабочем порядке менеджером по продажам и бухгалтерией по
расчётам с контрагентами без оформления корректировочного УПД на возврат товара.

## 7. Сроки и ответственность

7.1. Общий срок от согласования возврата с клиентом до оформления корректировочного УПД не должен
превышать пяти рабочих дней.

7.2. Ответственность за своевременную передачу основания для возврата в бухгалтерию несёт менеджер по
продажам.

7.3. Ответственность за своевременное оформление корректировочного УПД несёт главный бухгалтер.

7.4. Менеджер по продажам фиксирует факт и дату возврата в реестре рекламаций SALES-REESTR-REKLAM-2026,
если возврат оформлен по рекламации.

7.5. Нарушение срока по пункту 7.1 фиксируется менеджером по продажам в переписке с бухгалтерией и, при
повторном нарушении по вине одного подразделения, доводится до коммерческого директора для решения
организационных вопросов.

## 8. Взаимодействие со складом готовой продукции

8.1. Начальник склада готовой продукции принимает возвращаемую продукцию только при наличии основания
возврата, оформленного по разделу 5, и фиксирует приёмку в 1С:ERP датой фактического поступления.

8.2. Если возвращаемая продукция подлежит утилизации, а не повторному использованию, решение об этом
принимает начальник ОТК на основании акта о браке; самостоятельное решение об утилизации складом не
допускается.

8.3. Продукция, возвращённая по соглашению сторон (раздел 4) и признанная годной к дальнейшей
реализации, возвращается на склад как товарный остаток без оформления акта о браке.
