## 1. Назначение каталога

1.1. Настоящий каталог содержит номенклатуру корпусных деталей, изготавливаемых ГК «Родос-Деталь» на Ковровской площадке.

1.2. Каталог применяется менеджерами по продажам при подготовке коммерческих предложений и заказчиками при уточнении характеристик продукции.

1.3. Основные заказчики корпусных деталей — АО «Редмаш» и ООО «Конвейер-Системс».

## 2. Номенклатура корпусных деталей

2.1. Группе «корпусные детали» соответствует стандартный срок изготовления 30 рабочих дней; ускоренный срок — 20 рабочих дней с наценкой 25 % к цене партии в соответствии с SALES-SROKI-2026.

## 3. Материалы и заготовки

3.1. Корпуса редукторов Р-160 и Р-200 (61.05.20, 61.05.21, 61.05.22) и корпус подшипникового узла (61.05.23) изготавливаются из отливки чугуна СЧ20 ГОСТ 1412-85, поставляемой по договору с ООО «Литейный двор».

3.2. Плита опорная натяжной станции (61.05.24) изготавливается из листовой стали 45 ГОСТ 1050-2013 с цинковым покрытием Ц9.хр по ГОСТ 9.306-85.

3.3. Литейные заготовки для корпусных деталей поставляются ООО «Литейный двор» по договору ЛД-2024/27; допустимый уровень брака по литью, установленный договором, — не более 3 % партии.

## 4. Контроль

4.1. Линейные размеры, межосевые расстояния и плоскостность контролируются по методике ОТК-МИ-001.

4.2. Шероховатость поверхностей контролируется по методике ОТК-МИ-004.

4.3. Толщина цинкового покрытия детали 61.05.24 контролируется по методике ОТК-МИ-005.

4.4. Расточная обработка корпусов выполняется на токарно-фрезерном центре Sinumerik 828D / СТЦ-1730 (инв. № ОС-1250); цинкование плиты 61.05.24 — на линии цинкования АГ-40 (инв. № ОС-0903).

## 5. Технические условия

5.1. Технические условия на корпус редуктора Р-200, нижняя часть (61.05.22) — TU-61-05-22.

5.2. Технические условия на остальные позиции группы оформляются по запросу заказчика в порядке, установленном регламентом SALES-REGL-KP.

## 6. Порядок заказа

6.1. Коммерческое предложение по номенклатуре настоящего каталога готовится менеджером по продажам по форме SALES-SHABLON-KP либо, при ускоренном сроке изготовления, по форме SALES-SHABLON-KP-SROCH.

6.2. Заказ оформляется в производство после подписания спецификации к договору поставки в порядке, установленном регламентом SALES-REGL-ZAKAZ.

6.3. Корпусные детали 61.05.20 и 61.05.21 (нижняя часть и крышка редуктора Р-160) заказываются, как правило, комплектом; срок изготовления комплекта определяется как для одной партии группы «корпусные детали».
