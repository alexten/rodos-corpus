Техническое заключение № 2026-07 от 23.09.2026 по заявке АО «Гидромаш-Юг» от 22.09.2026.

Заключение составлено **инженером по продажам** Цветковой М. П. в порядке пункта 3.2 регламента
SALES-REGL-KP. Без него менеджер по продажам предложение по этой заявке не формирует.

## 1. Почему заключение потребовалось

1.1. Пункт 3.1 регламента SALES-REGL-KP требует технического заключения, если заявка содержит изменение
конструкции относительно серийного чертежа, нестандартный материал, нестандартный допуск либо если
действующих технических условий на изделие нет.

1.2. Заявка содержит **нестандартный допуск**: заказчик просит шероховатость поверхности штока
Ra 0,8 вместо серийной Ra 1,6 по чертежу 73.22.30. Это и есть основание пункта 3.1; остальные три
признака в заявке отсутствуют — конструкция серийная, материал по чертежу, технические условия
действуют.

1.3. Срок подготовки предложения по пункту 2.2 регламента SALES-REGL-KP — не более двух рабочих дней с
даты получения заявки — на эту заявку не распространяется: он установлен для случаев, когда техническое
заключение не требуется. Фактический срок — от даты настоящего заключения.

## 2. Заключение по существу

2.1. Требуемая шероховатость Ra 0,8 достижима на имеющемся оборудовании введением дополнительной
операции полирования после шлифования. Изменение конструкции не требуется, чертёж не пересматривается.

2.2. Дополнительная операция увеличивает трудоёмкость партии и производственный цикл: срок изготовления
группы «гидроцилиндры и детали» увеличивается на 3 рабочих дня против стандартных 25 рабочих дней
таблицы раздела 2 документа SALES-SROKI-2026.

2.3. Ограничение по объёму: при партии свыше 60 штук полирование становится узким местом участка, и срок
требует отдельного согласования с производственно-диспетчерской службой. Заявленные 50 штук в это
ограничение не попадают.

2.4. Технические условия на изделие действуют и пересмотра не требуют; заключение о соответствии
поставляемой продукции даётся по действующим ТУ.

## 3. Вывод для коммерческого предложения

3.1. Предложение может быть сформировано. Срок изготовления указать 28 рабочих дней вместо 25.

3.2. Отдельной наценки за нестандартный допуск регламентами не предусмотрено; цена — по прайс-листу.
