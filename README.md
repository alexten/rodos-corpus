# Родос-Корпус

Синтетический корпус документов вымышленного машиностроительного предприятия: **372 документа** в семи
форматах, выведенные из одной модели мира, побайтово воспроизводимые, под лицензией MIT.

> ## ⚠️ Предприятие вымышлено
>
> **ГК «Родос-Деталь» не существует.** Её площадки, цеха, сотрудники, контрагенты, договоры, детали,
> станки и документы придуманы целиком. Совпадения с настоящими организациями и людьми не подразумевались.
>
> **Все числовые реквизиты невозможны по построению.** ИНН, КПП, ОГРН, БИК и расчётные счета начинаются
> с `00` — такого кода региона и такого кода банка не существует, поэтому эти реквизиты не могут
> совпасть ни с одной живой организацией. Это не обещание, а свойство, которое проверяет линтер по
> тексту документов: `rodos-corpus lint`.
>
> **Внутренние документы настоящих компаний не использовались** — ни в каком виде, даже обезличенные.
> Реальны только нормативные акты (ТК РФ, приказы Минтруда, ГОСТы): как официальные документы они не
> охраняются авторским правом (ст. 1259 ГК РФ), и их источники перечислены в
> [`PROVENANCE.md`](src/rodos_corpus/data/corpus/PROVENANCE.md).
>
> Персональные данные — пять заведомо фиктивных фикстур в изолированном каталоге `_pii/`; они
> существуют затем, чтобы потребитель мог проверить, что его детектор их ловит.

## Зачем это

Чтобы показать работающую систему поиска по документам, нужны документы. Настоящие взять нельзя:
обезличивание ненадёжно, а переписанный чужой регламент остаётся производным произведением. Публичные
наборы либо игрушечные, либо не похожи на то, что лежит у предприятия: редакции, грифы, сканы без
текстового слоя, письма с вложениями, первичка в XML.

Этот корпус собран как замена: связный мир, из которого документы выведены, а не написаны по одному.
Из-за этого эталоны для оценки тоже выводятся из мира, а не сочиняются вручную, — и корпус можно
растить, не теряя согласованности.

Он используется двумя приложениями:
[«Родос-Ассистент»](https://github.com/alexten/rodos-assistant) отвечает по этим документам,
«Родос-Агент» действует по их регламентам в корпоративных системах.

## Что внутри

```
src/rodos_corpus/data/
├── world/            13 справочников: площадки, цеха, люди, роли, детали, материалы,
│                     оборудование, продукция, контрагенты, договоры, ЦФО, календарь, ИТ-системы
├── corpus/
│   ├── source/       исходники: YAML-шапка (карточка) + тело в ограниченном markdown
│   ├── rendered/     DOCX · PDF · XLSX · EML · XML · TXT · PDF-скан без текстового слоя
│   │   └── <пространство>/   production · finance · sales · it · common · _pii
│   └── cards/        карточка каждого документа: метаданные, путь, размер, sha256
├── stream/           поток входящих событий: письма контрагентов, присланные документы
├── assets/fonts/     DejaVu — в репозитории, иначе PDF меняет байты вместе с версией шрифта
└── MANIFEST.json     doc_id → sha256 и версия корпуса
```

Состав: 90 типов документов, от технологических карт и регламентов ОТК до УПД, счетов, реестров,
переписки с контрагентами и разборов рекламаций по методике 8D. Документы живут редакциями
(`status: superseded` + `superseded_by`), противоречат друг другу там, где это задумано, и ссылаются
друг на друга.

## Использование

```toml
[project]
dependencies = ["rodos-corpus"]

[tool.uv.sources]
rodos-corpus = { git = "https://github.com/alexten/rodos-corpus", tag = "v1.0.0" }
```

```python
from rodos_corpus import World, load_all, rendered_root, rendered_path, manifest

world = World.load()                    # модель мира
docs = load_all()                       # 372 SourceDoc: карточка, тело, путь
drop_folder = rendered_root()           # папка выгрузки; первый подкаталог — ключ пространства
path = rendered_path("DOG-PP-2025-14")  # файл документа
version = manifest()["version"]         # что записать в отчёт прогона оценки
```

`rendered_root()` устроен так, что его можно отдать приёмной программе как папку выгрузки: первый
подкаталог под ним — ключ пространства, и это подсказка маршрутизации «как минимум это пространство».

## Команды

```bash
rodos-corpus lint       # согласованность мира, исходников и фиктивность реквизитов
rodos-corpus stats      # состав по пространствам, типам, форматам, статусам
rodos-corpus verify     # сверить файлы с описью
rodos-corpus path rendered
rodos-corpus generate   # породить исходники из модели мира   (нужен extra «build»)
rodos-corpus render     # отрендерить исходники и карточки    (нужен extra «build»)
```

## Воспроизводимость — проверяемая, а не обещанная

Пересборка обязана давать **те же байты**: хеш документа — это его идентичность, по нему идёт
дедупликация при приёме и сравнение прогонов оценки между собой. Если хеши плывут сами по себе, два
прогона нельзя сравнить, а `git diff` перестаёт быть сигналом.

CI гоняет `generate && render && git diff --exit-code` на чужой машине. Закрытые источники
недетерминизма ([ADR-0011](docs/adr/0011-byte-reproducible-corpus.md)):

| Источник | Как закрыт |
|---|---|
| Время сборки | фиксированное `BUILD_TIME`, им же переписываются времена записей в zip и `docProps/core.xml` |
| Псевдослучайность | `random.Random(<стабильный ключ>)`; встроенный `hash()` запрещён — для строк он рандомизируется при каждом запуске интерпретатора |
| Шум растра в сканах | тот же засеянный генератор вместо `Image.effect_noise`, который берёт энтропию у системы |
| Шрифты | лежат в репозитории: fpdf встраивает подмножество глифов, другая версия DejaVu даёт другие байты |
| Версия Python | `.python-version` = 3.12: в разных версиях по-разному сворачиваются заголовки писем |
| Часовой пояс сборщика | дата создания PDF с явной зоной UTC — наивную дату fpdf дополняет зоной машины |

Каждый из них нашёлся поломкой, а не рассуждением; последние два — только на чужой машине в CI.

## Происхождение материала

Разделено по источнику ([ADR-0008](docs/adr/0008-corpus-provenance.md)):

- **нормативные акты** (ТК РФ, приказы Минтруда, ГОСТы, унифицированные формы) — дословно, с указанием
  источника и даты снимка: как официальные документы они не охраняются авторским правом;
- **структура отраслевых документов** — изучена по открытым публикациям предприятий, текст написан свой;
- **внутренние документы настоящих компаний** — не использованы никак.

Подробности и список источников: [`PROVENANCE.md`](src/rodos_corpus/data/corpus/PROVENANCE.md).
